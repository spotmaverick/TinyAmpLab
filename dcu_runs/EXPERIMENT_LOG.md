# DCU 地毯式架构搜索 — 实验总记录

## 目标

找到 **test NRMS 优于 A2 Lite 同规模复现**、且**模拟电路实现代价可控**的自研架构与对应参数规模。
所有对比在同一协议下进行，保证数字可归因。

## 统一协议（全部 run 共用）

- 数据：TSA15 管箱配对（train 152.5s / val 20.6s / test 38.1s，48kHz float32，独立 test 段）
- 训练：MSE 损失、恒定 LR 3e-3、Adam、batch 4s、seed 7、torch 1.10 + DTK 22.04（海光 C878180）
- 指标：NRMS（越低越好）+ corr，test 段为未见数据；电路成本记账（params / RF / MACs per sample / 流式激活状态 KB）
- 已知锚点 @100ep：NAM MLP 1650 → test 0.4828；WaveNet 复现 2505 → test **0.2207**；dual sequential 640 → ≈0.65

## 电路友好性准则（记录在案，用于最终裁决）

1. 仅用：延迟线抽头（卷积）、Crossbar MAC（矩阵乘）、模拟乘法器（门控）、简单非线性（tanh/sigmoid/ReLU/LeakyReLU）、加法
2. 禁用（高代价）：归一化层、注意力、softmax、FFT、跨层 gather
3. 因果流式：激活状态 = Σ(dilation×ch)×4B，需落在片上存储可接受范围（≈数十 KB）
4. 权重规模决定浮栅/Crossbar 阵列面积；等 NRMS 下参数少者优先

## P0 结果复盘（01:20，100ep/seed7/MSE）

| run | params | gate | test NRMS | test corr |
|---|---|---|---|---|
| a2lite（超越靶子） | 2178 | classic | 0.2589 | 0.9668 |
| **v_tcn812** | **2221** | **无门控** | **0.2198** | 0.9762 |
| v_classic814 | 3583 | classic | 0.2124 | 0.9780 |
| v_sgate814 | 3583 | sgate(f·tanh g) | 0.2475 | 0.9691 |
| lgw1 | 5599 | dual | 0.2231 | 0.9751 |
| lgw2 | 11799 | dual | **0.1948** | 0.9827 |
| WaveNet 复现 | 2505 | classic | 0.2207 | 0.9758 |

**结论**：
1. **用户目标已阶段性达成**：v_tcn812 以同等参数（2221 vs 2178）test NRMS 0.2198，比 a2lite 复现 0.2589 低 15%。
2. 等参门控对决（3583）：classic > sgate（0.2124 vs 0.2475），原始 f·tanh(g) 门控淘汰。
3. 无门控 TCN 竟然与 WaveNet 门控相当（0.2198 vs 0.2207）——中规模下门控收益存疑，深度/宽度才是主驱动。
4. dual 门控在大参数下爆发（11799 → 0.1948），但中规模性价比不如 classic；预算内表现待 P1 验证。

## 量化敏感性（本地 CPU，逐张量对称量化，TSA15 test）

| 模型 | fp32 | 8bit | 6bit | 5bit | 4bit |
|---|---|---|---|---|---|
| v_tcn812 | 0.2198 | 0.2256 | 0.2596 | 0.2354* | 0.5385 |
| lgw2 | 0.1948 | 0.1956 | 0.2021 | 0.2460 | 0.4152 |
| a2lite | 0.2589 | 0.2574 | 0.2755 | 0.2922 | 0.3509 |

*5bit 优于 6bit 为逐张量 max 缩放伪影，待逐通道缩放复检。结论：lgw2 量化鲁棒性最好；4bit 全面崩溃 → 模拟设计按 ≥6-bit 浮栅。
