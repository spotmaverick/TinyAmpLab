# 模拟电路友好架构设计 v1（对标官方 A2）

> 日期：2026-11-26
> 目标：在**官方 NAM 框架内**（同一数据、同一训练器、同一评测口径）找到一种**物理元件网络容易实现**、
> 且精度能匹敌/超越官方 A2 Slimmable 的架构。
> 硬性要求：不再自写 A2 实现；A2 一律用官方代码 + 官方配置 + 官方训练器。

## 一、为什么此前走弯路（教训）

| 弯路 | 问题 |
|---|---|
| 自己重写 A2 (`a2_model.py`) | 参数 15697 vs 官方 15685，差 12 个；**永远在复现别人的东西**，且失去官方 `.nam` 生态 |

| 用自研训练循环跑对照 | 与官方 esr 口径、数据划分不完全一致，跨机结果不可比 |

**正确做法**：官方框架 + 官方 A2 权重与协议做锚点；我们只在「架构」这一个变量上创新，
并让每个候选都以**模拟实现的物理成本**作为并行目标，而不是只看数字 NRMS。

## 二、模拟电路的物理成本模型（设计的第一性依据）

模拟计算（跨导乘法器阵列 + KCL 求和 + 浮栅存储）的真实成本，不是参数量，而是这四个：

| 成本项 | 物理来源 | 为什么贵 |
|---|---|---|
| **交叉开关数 X** | 每个权重 = 一对差分对/一个 Gilbert 单元 | 面积正比于 X，是芯片面积主导项 |
| **MACs/sample** | 每采样需要的乘法次数 | 决定功耗与所需带宽 |
| **累加链深度** | 一条 KCL 求和线上串联的器件数 | 深链 → 寄生电容大 → 速度慢、失配累积 |
| **延迟线抽头数** | 存储过去采样所需的采样保持/电容单元 | 面积 + 时钟馈通 + 漏电；这是**模拟独有**的大成本 |
| **摆幅需求 Vsat** | 信号动态范围 / 参考电压 | 摆幅越大 → 功耗平方增长；实测 A2 Lite 需 Vsat=16，是 LGW 的 10× |

> 关键实测（`src/analog/analog_sim_wavenet.py`）：A2 Lite 的残差流从 0.04 累积到 2.2、
> preact 峰值 14.6，比 LGW 大 ~20×；Gilbert 三次失真在 Vsat=1.5 时把 NRMS 毁到 0.64。
> **残差累加深度是摆幅需求的直接原因** —— 这是设计必须解决的问题。

## 三、设计原则（从物理成本倒推）

**P1 · 消除密集交叉开关。**
A2 的 3-tap dilated conv 是全连接 `ch×ch×3`，在 ch=12 时占参数的 68%、
交叉开关的绝大部分。物理上这是一块 12×12 的乘法器阵列，**12 条求和链每条累加 36 项**。
→ 改 depthwise（每通道独立 3-tap）把交叉开关从 ch²·3 降到 ch·3，累加链从 36 降到 3。
代价：表达力下降（无通道混合），必须用别处补回来。

**P2 · 用「分组」而非「全连接」做通道混合。**
P1 之后，通道混合只剩 1×1 层（`layer1x1` ch²）。ch=24 时它占参数增量 76%，此时
交叉开关反超全连接 A2 —— 这是 `dw_ch24` 效率随宽度递减（+6.9%）的根本原因。
→ 1×1 用 **分组卷积（groups）或低秩分解**，把 ch² 降到 ch·ch/g 或 2·ch·r。

**P3 · 避免残差流无限累积（控制摆幅）。**
A2 的残差 `y = y + layer1x1(z)` 在 15 层里把幅度放大到 2.2、preact 峰值 14.6。
→ 引入**归一化/缩放约束**或**更浅的残差累加**，把动态范围压在低摆幅内。
这是 Analog Devices 类设计里 may 决定成败的一点：**能算对但摆幅要求 10× 的方案，物理上不可用**。

**P4 · 延迟线预算优先于参数预算。**
A2 的 RF = 5386 采样 = 112ms，需要 5386 个采样保持单元。
这不是参数，但**在模拟里比参数贵得多**。
→ 明确把「延迟线抽头数」作为一等约束，接受为缩短它而付的精度代价。
（已有实测：lite 的 RF 减半 → +11~13% 退化，是真实 trade-off。）

**P5 · 激活函数必须是器件天然的。**
差分对饱和天然产生 `tanh`；二极管/亚阈值 MOS 天然产生 `exp`。
→ 优先 `tanh`（官方 WaveNet 已用），**避免 ReLU**（需要理想整流器，实际有失调与死区，
实测 `SIGMA_OFFSET` 会直接注入误差）。

**P6 · 递归结构是模拟的天然盟友（待验证的新方向）。**
状态空间/IIR 递归：状态存在**电容电荷**上，不需要长延迟线。
一个 N 阶 IIR 只用 N 个电容就能实现 5386 抽头的等效记忆。
→ 这是**唯一能同时击穿「延迟线成本」与「参数成本」的结构**，值得作为独立方向验证。
风险：递归的长时间稳定性在模拟里难保证（极点漂移、噪声累积），需实测。

## 四、候选架构族（全部可用官方配置或官方注册机制表达）

### 族 A：官方配置内可表达（零新代码）

官方 `_LayerArrayConfig` 已支持的旋钮：`channels` / `bottleneck` / `kernel_size` /
`groups_input` / `groups_input_mixin` / `layer_1x1_config.groups` / `dilations` / `activation`。

| 变体 | 改动 | 物理收益 | 预期代价 |
|---|---|---|---|
| `A-dw` | `groups_input = channels`（depthwise conv） | 交叉开关 ch²·k → ch·k | 无通道混合 |
| `A-grp4` | `groups_input = 4` | 交叉开关降至 1/4 | 轻微 |
| `A-bneck` | `bottleneck < channels` | conv 输出维度降 | 表达力 |
| `A-k3` | `kernel_size 6→3` | 每层乘法器减半 | RF 减半 |
| `A-l1grp` | `layer_1x1_config.groups = 4` | 1×1 交叉开关降至 1/4 | 轻微 |

### 族 B：递归/状态空间（需注册新模型，但复用官方训练器）

| `B-lstm` | 官方自带 LSTM（已有） | 无延迟线，权重少 |

## 五、评价口径（唯一标准）

**主指标**：官方 esr（= NRMS²），在**同一 test 段**（TSA15 test，38.1s）上全段推理。
**对照锚点**：官方 A2 Slimmable 同一配置、同一 100ep 官方协议、同一 GPU。
**并行指标**：交叉开关数、MACs/sample、累加链深度、延迟线抽头、摆幅需求。

**成功判据**（预先登记，避免事后合理化）：
- Lite 档：候选在 **≤A2 Lite 的物理成本**下，test esr 不超过 A2 Lite 的 **1.15×**（即 NRMS 不超过 1.07×）→ 匹敌
- 若同时物理成本更低且 esr 更好 → 超越
- Full 档：Lite 成功后，用同族放大到 ch12 级别再比
