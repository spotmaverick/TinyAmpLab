# P2 实验报告：误差源留一消融 + 口径矛盾归因

> 执行：bw2（作业 1253343，1×BW gfx936，torch 2.9.0）+ z100（作业 50067655，1×Z100SM，torch 2.1.0）
> 耗时：322s / 559s（同一份脚本、同一批权重、同一份音频、同一组 MC 种子）
> 口径：V_SAT=16，5 秒 tsa15，5 种子（s7/s11/s23/s31/s37），MC=8
> 脚本：`p2_ablate.py`（md5 `355d5674e0c67acbef1acd93b0319d2b`，两机一致）
> 产物：`runs_remote/p2_ablate_1127/`

## 0. 一句话结论

**器件退化有 67~74% 来自 Gilbert 单元的 tanh 饱和非线性，且种子间 32.1% 的方差几乎全部由它产生（关掉后降到 5.0%）。** 「38.7% 器件方差」不是训练随机性，是工作点问题——这直接推翻了 P0「训练侧器件正则」的原始理由。

## 1. 为什么做这个

两条线索逼出来的：

1. 上轮 V_SAT 扫描发现种子间 CV 随工作点骤降（V_SAT=16 时 30.5% → V_SAT≥96 时 6.8%），
   暗示方差可能不是结构性的。
2. 核对脚本时发现**口径矛盾**：`analog_sim_generic.P` 的实际默认值
   （`BITS=6, BETA_H3=0.002, SIGMA_MISMATCH=0.01, SIGMA_OFFSET=0.005, SNR_DB=70`）
   与 `HANDOVER_20261126.md` 记录的档位
   （`BITS=8, BETA_H3=0.3, SIGMA_MISMATCH=0.02, SIGMA_OFFSET=0.001, SNR_DB=60`）
   不一致，**β 差 150 倍**。上轮 V_SAT 扫描继承的是代码口径，却拿文档口径的 A2 基准对比。

## 3. 核心结论：总退化预算分解

`总退化 = BASE − 数字模型`（全关所有非理想性 = 0.0594，即数字精度天花板）

### code 口径（β=0.002，BITS=6）

| 关掉此项 | 中位 NRMS | 降幅 | 占总退化 |
|---|---:|---:|---:|
| **Gilbert 非线性 (tanh+β)** | **0.0888** | **+0.0589** | **66.7%** |
| 量化 | 0.1385 | +0.0092 | 10.4% |
| 权重失配 | 0.1534 | −0.0057 | −6.5% |
| 温漂 | 0.1525 | −0.0048 | −5.5% |
| 差分对失调 | 0.1460 | +0.0017 | 1.9% |
| 热噪声 | 0.1477 | +0.0000 | 0.0% |
| 基准 | 0.1477 | — | — |
| 全关（数字） | 0.0594 | +0.0883 | 100% |

### doc 口径（β=0.3，BITS=8）

| 关掉此项 | 中位 NRMS | 降幅 | 占总退化 |
|---|---:|---:|---:|
| **Gilbert 非线性 (tanh+β)** | **0.0814** | **+0.0632** | **74.2%** |
| 温漂 | 0.1289 | +0.0157 | 18.5% |
| 权重失配 | 0.1312 | +0.0133 | 15.7% |
| 量化 | 0.1417 | +0.0028 | 3.3% |
| 差分对失调 | 0.1445 | +0.0000 | 0.0% |
| 热噪声 | 0.1446 | +0.0000 | 0.0% |

**两套口径下结论一致：非线性一家独大（67~74%），其余全部个位数。**
交互项在 code 口径占 +32.9%（失配/温漂出现负降幅 → 它们与非线性有部分抵消），
doc 口径为 −11.7%，都说明**误差源不是可加独立的，强项之间会相互遮蔽**。

### 3.1 ⚠ `BETA_H3=0` 的真实语义（本次踩到的坑）

`_gilbert` 的实现是：

```python
if self.p["BETA_H3"] <= 0:
    return prod.sum(dim=2)          # 直接绕过 tanh！
vs = self.p["V_SAT"]
return (vs * torch.tanh(prod * (1 + β·x̂²)/vs)).sum(dim=2)
```

`β=0` 走的是 `sum`，**把「β 三次项」和「tanh 削顶」一起关掉了**。所以这个 case 不能叫
「关三次失真」，它实际是「关整套 Gilbert 非线性」。冒烟阶段我误标为 `BETA3`，此处更正为 `NONLIN`。

**这个发现本身有独立价值**：既然关掉整个非线性只降 0.0589/0.1477，
而 β 从 0.002 改到 0.3（150 倍）只让 NRMS 从 0.1564 变到 0.1321，
说明**决定退化的是 tanh 削顶，不是 β 的取值**。β 只是在高 V_SAT 时才有意义。

## 4. 种子间方差归因：32.1% → 5.0%

| 配置 | 中位 NRMS | 种子间 CV | max/min |
|---|---:|---:|---:|
| BASE（全开） | 0.1477 | **32.1%** | 2.35 |
| 关 Gilbert 非线性 | 0.0888 | **5.0%** | 1.17 |
| 全关（数字） | 0.0594 | 1.7% | 1.04 |

逐种子看降幅：

| seed | BASE | 关非线性后 | 降幅 |
|---|---:|---:|---:|
| s7 | 0.0992 | 0.0823 | 17% |
| s11 | 0.2074 | 0.0891 | **57%** |
| s23 | 0.1166 | 0.0963 | 17% |
| s31 | 0.2328 | 0.0888 | **62%** |
| s37 | 0.1477 | 0.0876 | 41% |

**结论：坏的种子不是「训练得不好」，是「被削顶削得更惨」。** 关掉削顶后五个种子全部收敛到
0.082~0.096（CV 5%），差异就此消失。

### 4.1 反直觉：饱和越深，退化反而越轻

| seed | NRMS | 最深饱和层 | rms/V_SAT | 总饱和量 | head/V_SAT |
|---|---:|---:|---:|---:|---:|
| s7 | 0.1045 | L9 | 0.28 | 0.0201 | 1.17 |
| s11 | **0.2111** | L9 | **0.19** | **0.0058** | 1.05 |
| s23 | 0.1231 | L9 | 0.32 | 0.0153 | 1.33 |
| s31 | **0.2378** | L9 | 0.32 | 0.0249 | 1.35 |
| s37 | 0.1545 | L9 | 0.31 | 0.0280 | 1.29 |

相关系数（5 样本，仅作方向参考）：

| 变量对 | Pearson r |
|---|---:|
| NRMS vs L9 rms/V_SAT | **−0.29** |
| NRMS vs 逐层饱和深度之和 | **−0.47** |
| NRMS vs head 累加和 RMS | −0.02 |

**s11 的饱和深度最浅、总饱和量最少，退化却最重。** 饱和量与退化是负相关。
**所以不能用「饱和深度」作设计指标**——这是个容易踩的坑。

已排除的解释：
- 残差通路（layer1x1）饱和率全部 < 0.001，不构成差异来源。
- head 累加摆幅与 NRMS 相关性 −0.02，与 P-1 结论一致（摆幅是结构常数）。

尚在候选的解释：**preact 分布的尖锐度（峰均比）**。L6/L7 的峰均比呈现
s31(18.6/18.7) > s37(19.4/20.4) ≈ s23(17.1) > s11(16.0) > s7(14.1) 的排序，
与 NRMS 排序部分吻合但 s23 是例外。**这条需要专门实验（preact 直方图 + 谱分析）才能定论，
本次不下判断。**

## 5. 口径矛盾归因（单变量扫描）

`code → doc` 同时改了 6 个参数，直接相减是混杂效应。逐参数单改的结果（s37，MC=8）：

| 单改这一项为 doc 值 | 中位 NRMS | 相对 code | 占总 gap |
|---|---:|---:|---:|
| `BETA_H3` 0.002 → 0.3 | 0.1386 | −0.0178 | **73%** |
| `BITS` 6 → 8 | 0.1454 | −0.0110 | 45% |
| `SIGMA_MISMATCH` 0.01 → 0.02 | 0.1589 | +0.0025 | −10% |
| `SIGMA_OFFSET` 0.005 → 0.001 | 0.1550 | −0.0013 | 5% |
| `SNR_DB` 70 → 60 | 0.1564 | +0.0000 | −0% |
| `DRIFT` 0.03 → 0.03（未变） | 0.1564 | +0.0000 | −0% |
| 全量切换 code → doc | 0.1321 | −0.0243 | 100% |

**β 和 BITS 是主因，合计解释 118%（超 100% 说明两者有相互抵消）。**

### 5.1 哪个口径是历史真实口径？

**β=0.002 才是**。证据在 `HETEROGENEOUS_RUN_2026-11-25.md`：
单因素诊断表里写的是「**+三次失真 β=0.002** → NRMS 2.1482」，且给出了完整的因果链
（preact 峰值 90.52 vs Vsat 16 → 失真 +801.6%）。β=0.002 在这个量级就能造成灾难性失真，
说明它是被真实使用过并产出过结论的参数。

**因此 `HANDOVER_20261126.md` 与 `TARGET_TOPOLOGY_STATUS.md` 里写的 `BETA_H3=0.3` 是文档笔误，
应统一改为 0.002。** 但要注意：doc 口径下 NRMS 更低（0.1446 vs 0.1477），
因为 β=0.3 会让 preact 更早进入 tanh 的**压缩**区，反而抑制了尖峰。
**这不是「β 越大越好」，是「β 大到一定程度后 tanh 提前介入改变了工作点」。**

## 6. 对既有结论的裁决

| 既有说法 | 出处 | 裁决 |
|---|---|---|
| 「Gilbert 三次失真 100% 是决定性因素」 | HANDOVER §2 | **方向正确、数字需修正**：含 tanh 的整套非线性占 67~74%，不是 100% |
| 「β 默认 0.3」 | HANDOVER §2 / TARGET §1 | **错误**：实际 0.002（HETEROGENEOUS 报告可证） |
| 「BITS 默认 8」 | TARGET §1 | **错误**：代码实际 6 |
| 「器件方差 38.7%，是最大风险，P0 该做训练侧器件正则」 | SEEDS §P0 | **需重排**：方差 32% 几乎全是削顶造成，关掉非线性即降至 5%。**P0 第一优先应是工作点（提高 V_SAT 或降 preact 幅度），不是加训练正则** |
| 「head 累加摆幅是结构常数」 | P-1 §7 | **维持**：本次独立复现，与 NRMS 相关性 −0.02 |
| `V_add ≥ 12×V_SAT` | P-1 §3 | **维持**：head 累加和 1.05~1.35×V_SAT 复现 |

## 7. 修正后的 P0 路线

原来的 P0（训练时加器件失真正则）**降级**。新的优先级：

| 序 | 动作 | 依据 | 成本 |
|---|---|---|---|
| **P0-1** | 提高 V_SAT 到 48~64（工艺/供电侧） | 上轮 V_SAT 扫描：48 时中位退化压到 1.06×，CV 降到 8.5% | 工艺成本 |
| **P0-2** | 降 preact 幅度（Layer Gain Taper / 逐层 rescale） | 本次：非线性占 67~74% 退化，preact 幅度是其唯一自变量 | 零训练成本 |
| P0-3 | 修文档口径（β=0.002、BITS=6），重算历史退化比 | 本次 §5 | 半天 |
| 降级 | 训练时加器件失真正则 | 方差已证明来自工作点而非训练随机性 | 3h |
| 维持 | P0a 扩 13 种子 | 仍需确认分布形状是否单峰（若双峰说明还有未识别的机理） | 1.5h |

## 8. 未决问题（需专门实验）

1. **为什么 s11 饱和最浅却退化最重？** 候选解释是 preact 峰均比（尖锐度），
   需 preact 直方图 + 频谱分析。这是本次最大的未解点，直接关系到能否用「饱和深度」做设计指标（目前答案：不能）。
2. **失配/温漂在 code 口径下出现负降幅**（关掉反而更差），说明它们与非线性有拮抗作用。
   这个拮抗关系是否稳定、是否可用来「故意引入失配抵消削顶」，值得单独验证。
3. **β 的最优值**：doc 口径（β=0.3）NRMS 反而更低。若这是真实的 tanh 提前压缩效应，
   存在一个「β 甜点」而非「β 越小越好」。需 β 扫描确认。
