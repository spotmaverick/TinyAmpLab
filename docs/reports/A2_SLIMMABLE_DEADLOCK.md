# 重大发现：官方 A2 Slimmable 的 12 通道分支从未被训练

> 发现时间：2026-11-26 19:00 CST
> 影响范围：**推翻 Round1 全部对比结论**（`A2_ALIGNED_ROUND1.md` 中的 −61% 优势不成立）
> 证据脚本：`src/tools/diag_deadlock.py`

## 一、一句话结论

官方 `nam_full_configs/models/wavenet_slimmable.json` 使用的
`init_strategy = "smallest_and_zeros"` 会**永久冻结** 12 通道分支：
初始化把大通道的 weight 与 bias 全部置零，而每一层的 `_input_mixer` 是
`bias=False`，导致这些通道的输入恒为 0、梯度恒为 0，**训练全程不更新**。

因此 Round1 里那个「A2 = test NRMS 0.1786」的基线，
实际上是 **A2 Lite（3 通道）** 的成绩，**不是 A2 Full（12 通道）**。

## 二、三条独立证据

### 证据 1：梯度活性扫描

同一份官方配置，只改 `init_strategy`，在全宽（ratio=1.0）前向下反传：

| ratio | `smallest_and_zeros` | `channel_causal` |
|---:|---:|---:|
| 0.0 | 5.53e-03 | 3.62e-02 |
| 0.4 | 5.53e-03 | 3.62e-02 |
| **0.5** | **0.0 ← 死锁** | 8.16e-01 |
| 0.6 | **0.0** | 8.16e-01 |
| 0.8 | **0.0** | 8.16e-01 |
| **1.0** | **0.0 ← 死锁** | **8.16e-01** |

关键点：ratio ≥ 0.5 后，**总梯度严格等于 0**（不是"很小"，是浮点零）。
且 ratio 0.0~0.4 的梯度值完全相同 —— 因为这几档都映射到同一个通道索引 `i=0`，
-loss 也完全相同，说明 12 通道前向的输出与 3 通道**逐位一致**。

### 证据 2：导出权重的零值比例

官方 100ep 训练产出的 `model.nam`：

```
total weights = 15686
nonzero       = 1088
zero          = 14598   (93.1% 为零)
```

1088 个非零 ≈ A2 Lite 的 1090 参数（`train_a2.py` 实测 `a2_ch3 params=1090`）。
**15686 个权重里有 93% 从未被写过。**

### 证据 3：逐层核查大通道

对 12 输出维的参数张量逐层统计大通道（索引 3:12）的绝对值之和：

```
12-输出维参数张量：大通道全零 46 个 / 大通道有非零 0 个
```

46 个张量**无一例外**全零。包括 `_rechannel`、所有 `_conv`、所有
`_input_mixer`、所有 `_layer1x1`、`_head_rechannel`。

## 三、根因分析（为什么是死锁而不是慢启动）

死锁需要同时满足两个条件，官方配置恰好都满足：

1. **权重与 bias 全零**（`_init_smallest_and_zeros` 主动清零 `weight[min_out:]` 与 `bias[min_out:]`）
2. **该通道的输入恒为零**（`_input_mixer` 配置为 `bias=False`，
   且上游 `_rechannel` 的大通道输出也为 0）

于是：
```
大通道输出 = W(大) · x(大) = 0 · 0 = 0
∂L/∂W(大) = ∂L/∂out · x(大)ᵀ = (非零) · 0 = 0
```
梯度严格为零 → 权重永远停在 0 → 输入永远为 0 → 自我维持的死循环。

**这与学习率、训练步数、优化器都无关，是拓扑性缺陷。**

而 `channel_causal` 策略的初始化方式不同（保留了跨通道因果结构，
不清零大通道的输入侧），因此大通道一上来就有非零梯度，能正常训练。

## 四、对 Round1 结论的修正

Round1 排行榜的核心叙事是「族 A 的 12 通道分组卷积，用 38% 参数打败了 A2 的 12 通道全连接」。现在看：

| | 训练时实际激活的通道 | 参数（有效） | 100ep test NRMS |
|---|---|---:|---:|
| A2 官方（`smallest_and_zeros`） | **3**（12 通道中 9 个死锁） | ~1090 | 0.1786 |
| a-grp4 | **12** | 5965 | 0.0775 |
| a-grp6-ch18 | **18** | 10567 | 0.0691 |

**这是拿"训练了 12 个通道的模型"比"训练了 3 个通道的模型"，不公平。**
正确对照应当是：

- **A2 Lite (3ch) vs 族 A 3ch**（同容量）
- **A2 Full (12ch，causal 初始化) vs 族 A 12ch**（同容量）

## 五、已采取的修正

1. **新建 `model_a2_causal.json`**：官方架构原样，仅把
   `init_strategy` 改为 `channel_causal`。已验证 ratio=1.0 梯度 3.73e-01 正常。
2. **新建 `model_a3ch.json`**：族 A 的 3 通道版本（ch=3, groups=1），
   用于与 A2 Lite 做同容量对比。已验证梯度 7.62e-02。
3. **第四批训练已启动**（`run_night4.sh`）：
   - `a2causal-300` × seed 7/11 —— A2 Full 的真实基线
   - `a2causal-100` × seed 7 —— 与 Round1 的 100ep 协议对齐，量化死锁影响
   - `a3ch-300` × seed 7 —— 族 A 3 通道

## 六、这条发现本身的价值

对用户的目标（探索模拟电路易实现的架构）而言，这个发现是**利好**：

1. **A2 的真实容量被高估了**。之前以为 A2 是 15685 参数、15324 交叉开关的
   全连接网络；实际上它只训练了 1090 参数、约 1/10 的交叉开关。
   用 5965 参数的 `a-grp4` 打赢"1090 有效参数"的模型，优势幅度要重新评估。
2. **但它同时说明 A2 的真正上限未知**。修正后的 12 通道 A2 可能显著强于 0.1786，
   也可能因为全连接结构反而更差 —— 必须实测。
3. **`smallest_and_zeros` 的死锁是官方实现的 bug**，任何用该配置做
   "slimmable 训练"的实验都会踩到。这一点值得在最终报告里明确记录。
