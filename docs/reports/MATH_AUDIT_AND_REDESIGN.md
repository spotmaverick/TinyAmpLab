## 一、审计结论：四条既有论断需要降级或推翻

### 1. 「架构效率是主瓶颈，standard 比 LGW 好 2.7 倍」——**结论强度错误**

原文（d1）用 standard(13801 参数, 0.0653) 对比 LGW 冠军(2149 参数, 0.1736)，称同协议差 2.7 倍，"只能归因于架构"。

**问题：这是 6.4 倍参数量的对比，不是等参对比。**

用全部四档数据拟合参数效率幂律（R²=0.9988，拟合极干净）：

```
NRMS = 1.0968 × P^(-0.2975)
```

| 档位 | 参数 | 实测 | 拟合 | 残差 |
|---|---:|---:|---:|---:|
| nano | 841 | 0.1485 | 0.1479 | +0.4% |
| feather | 3025 | 0.1014 | 0.1011 | +0.3% |
| lite | 6553 | 0.0785 | 0.0803 | −2.2% |
| standard | 13801 | 0.0653 | 0.0643 | +1.5% |

按此幂律，2149 参数的 WaveNet 预期 NRMS≈0.1119；实测 LGW=0.1736。

**等参后架构差距是 1.55 倍，不是 2.7 倍。** 2.7 倍里混入了 6.4 倍参数优势。

此外两者 RF 也不同（11.3ms vs 85.3ms，7.5 倍）。这不是纯架构对比。已做的 d2（把 LGW 拉到 85ms）反而退化到 0.1893，说明 RF 不是 WaveNet 的优势来源——这一条反而是稳健的。

**修正后表述**：等参、等协议下 WaveNet 族架构效率约优于 LGW 族 1.5 倍；此前 2.7 倍的表述高估。

### 2. 「达到/超越 A2 Lite」——**目标定义本身混淆，需重新定义**

三个不同的"达到"，此前被混为一谈：

| 定义 | 现状 | 问题 |
|---|---|---|
| (a) NRMS≤0.0852（官方 A2 Lite） | 我方 lite 0.0785 已"达到" | 但用了 300ep 余弦退火 vs 官方 100ep，多花 3× 训练；不是同协议超越 |
| (b) 同等或更少参数超过 A2 Lite | 未达成 | lite 就是 A2 Lite 本身；自研 LGW 2149 参数 0.1736，差 2 倍 |
| (c) 用模拟元件实现并达到 A2 效果 | **未达成，且方向错了** | 物理仿真显示 lite 需 Vsat=16（10× 摆幅）、3× 器件、12× 延迟线 |

**关键冲突：数字精度最优的架构（lite/standard），恰恰是模拟实现最难的架构。** 继续在 WaveNet 全连接 conv 的路线上升精度，与"模拟可实现"目标是背道而驰的。

### 3. 「nano 缩 RF 反而更好」——**已撤回，此处记录置信度框架**

种子方差实测：

| 配置 | seed 7 | seed 11 | 相对差 |
|---|---:|---:|---:|
| nano_rf50 | 0.1412 | 0.1793 | 23.8% |
| feather_rf50 | 0.1005 | 0.1065 | 5.8% |
| lite_rf50 | 0.0885 | 0.0840 | 5.2% |

判据：**效应量必须大于种子方差才能宣称结论。**
- nano 的 −4.9% < 23.8% 噪声 → 作废
- lite 的 +12.8% > 5.2% 噪声 → 方向可信（但缺配对基线，强度仍降级）

### 4. 「线性模型不够，必须上大网络」——**验证成立（纠正一次脚本假象）**

曾用 numpy 复数直除得到"线性 NRMS=0.0000"，那是数值假象。用严格 Wiener-Hopf（训练段拟合、测试段评价、带正则）重做：

| FIR 长度 | test NRMS |
|---:|---:|
| 64 | 0.7795 |
| 256 | 0.7529 |
| 1024 | 0.7503 |
| 4096 | 0.7506 |

线性模型只能到 0.75，WaveNet standard 0.0653——**强非线性是任务本质，大容量有其必要性**。这条既有假设成立。

## 二、参数成本分解：模拟实现的瓶颈在哪里

A2 Lite 的 6553 参数分解：

| 算子 | 参数 | 占比例 | 模拟成本 |
|---|---:|---:|---|
| 3-tap dilated conv（全连接） | 4428 | 68% | 3× MAC + 85ms 延迟线 |
| 1×1 层（rechannel/mixer/layer1x1/head） | 2125 | 32% | 1× MAC，无延迟线 |

总模拟成本：**6228 MACs/sample + 4092 抽头延迟线 + 6553 浮栅单元**。

核心洞察：**dilated conv 是全连接 `Conv1d(ch,ch,3)`，成本随 ch² 增长**。若改成 depthwise `groups=ch`，参数降 60%（6553→2611），MACs 降 63%（6228→2286），而感受野不变。这正是模拟实现最需要的优化方向——但此前从未在严格等协议下测过它的精度代价。

> 注：此前有个 depthwise 复现（`nam_wavenet_baseline.py`）达到 0.2207，与官方 0.0852 差 2.6 倍。但那次同时改变了训练协议、对齐方式、门控实现，**从未单独归因于 depthwise**。这是本次实验要回答的核心问题。

## 三、重新定义目标

**旧目标（有问题）**：在数字 NRMS 上达到/超越 A2 Lite。

**新目标（可检验）**：

> 在模拟电路的三类硬约束下——(1) MACs/sample ≤ 2500，(2) 延迟线 ≤ 2048 抽头（≤42ms），(3) 电源电压摆幅 ≤ 2× 参考值——找到 test NRMS 最小的拓扑，并检验其能否进入 0.10–0.12 区间。

理由：
- 约束 (1)(2) 来自模拟面积/功耗的物理限制；
- 约束 (3) 来自实测：lite 因激活累积放大 20× 需 Vsat=16，否则 Gilbert 失真把 NRMS 毁到 0.64；
- 0.10–0.12 是"工程可用"的合理区间——比 LGW 的 0.3273 好 3 倍，接近 A2 Lite 数字值 0.0852。

**评价指标随之改变**：不再是单一数字 NRMS，而是"约束满足下的物理 NRMS"。物理仿真必须纳入模型选择循环，而不是事后补测。

## 四、新假设与判定性实验设计

### 假设（可证伪）

- **H1**：全连接 dilated conv → depthwise 的精度损失，是此前 depthwise 复现落后的主因。
  - 检验：`full_ch12` vs `dw_ch12`，等参数（除 conv 外全同）、等 RF、等协议、双种子。
  - 若两者差距 << 官方 0.0852 与旧复现 0.2207 的差距，H1 成立（差距主要来自 conv 类型）；否则不成立（来自其他混杂因素）。
- **H2**：depthwise + gated tanh + 宽通道补参，能进入 0.10–0.12。
  - 检验：`dw_ch24`（通道翻倍补回参数）是否随参数增加而改善。
- **H3**：depthwise 架构能承受短 RF（延迟线减半）。
  - 检验：`dw_ch12_rf50`、`dw_ch24_rf50`。

### 实验设计原则（针对此前缺陷）

| 此前缺陷 | 本次对策 |
|---|---|
| 单种子下结论 | 关键对照全部双种子（s7/s11） |
| 补测只跑一半格子，配对不成立 | 先跑 `full_ch12` 自验框架（应复现 0.0785），框架不可信则全部作废 |
| 多变量同时改变 | 每个变体只改一个变量（conv 类型 / 通道 / RF 各自独立） |
| 物理仿真事后补做 | 新脚本直接输出 MACs 与延迟线数，物理成本进决策 |

## 五、什么结果会推翻什么（预先登记判据）

为避免事后合理化，预先登记判定规则：

| 观察 | 结论 |
|---|---|
| `full_ch12` s7 不在 0.075–0.082 | **框架不可信**，全部对照作废，先修训练复现 |
| `dw_ch12` ≈ `full_ch12`（差<15%） | depthwise 几乎免费 → 直接得到 2.4× 模拟成本下降，重大进展 |
| `dw_ch12` 差 15–40% | depthwise 有代价但可接受 → 进入宽度/RF 补偿优化 |
| `dw_ch12` 差 >40%（接近 0.22） | H1 成立，全连接 conv 是精度关键 → 模拟路线需换思路（如低秩分解 conv） |
| `dw_ch24` 回到 <0.12 且 MACs<3000 | H2 成立 → 找到候选模拟拓扑，进入物理仿真 |
| 所有 dw 变体 >0.15 | 模拟友好拓扑与 A2 精度不可兼得 → 需重新审视目标可行性 |
