# Layer Gain Taper：修正残差缩放的作用点错误（2026-11-26 晚）

> 一句话结论：**之前把 α 乘在 `layer1x1` 上是错的**，因为官方
> `_Layer.forward` 的 head 累加路径根本不过 `layer1x1`。
> 正确的作用点是「每层激活之后」，一处 patch 同时覆盖两条路径。

## 一、错误是怎么发现的

用户批准加租一台 4090 后，我按计划先做「α 是否降低 V_SAT 需求」的验证。
过程中发现两个 bug，按严重程度排序：

### bug 1（低危，已修）：`sim_forward` 漏用 `residual_scale`

`analog_sim_generic.py` 的 `sim_forward` 里，残差注入写的是

```python
res_out = dev.conv(z, sd[f"{pre}._layer1x1.weight"], ...)   # 少了 alpha
y = y[:, :, -res_out.shape[2]:] + res_out + dev.noise(res_out.shape)
```

而 ScaledWaveNet 的权重是在 α=0.5 下训练的。首次 V_SAT 扫描因此输出
**V_SAT=4096 时 ESR=44.4**（数字基线应为 4.9e-03），差 4 个数量级 ——
仿真跑的是一个「残缺网络」，数据全部作废。

修复后重扫，4096 下 ESR=4.156e-03，与训练日志的 4.964e-03 同量级，仿真恢复可信。

### bug 2（高危，本次核心）：α 的作用位置本身是错的

修复 bug 1 后，V_SAT 扫描给出：

| V_SAT | 2 | 4 | 8 | 16 | 24 | 32 | 48 | **64** | 128 | 4096 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| ESR | 0.953 | 0.837 | 0.569 | 0.248 | 0.116 | 0.0587 | 0.0202 | **0.0100** | 0.0045 | 0.0042 |
| 相对理想 | 223× | 196× | 133× | 58× | 27× | 13.8× | 4.7× | **2.3×** | 1.1× | 1.0× |

**与未加 α 的 a-grp4 几乎一致**（那边同样要 V_SAT≈64 才到 2×）。
也就是说 α=0.5 对动态范围需求**毫无帮助**，与我的预期（"V_SAT=16 甚至 4 就够"）完全相反。

## 二、根因：官方 `_Layer.forward` 有两条独立路径

读官方 `nam/models/wavenet/_layer_array.py` 的关键两行：

```python
layer_output = post_activation
if self._layer1x1 is not None:
    layer_output = self._layer1x1(layer_output)      # 残差支路，过 layer1x1
...
head_output = post_activation                        # head 支路，**不过 layer1x1**
if self.head1x1 is not None:
    head_output = self.head1x1(head_output)[:, :, -out_length:]

residual = x[:, :, -layer_output.shape[2]:] + layer_output
return (residual, head_output)
```

而 `LayerArray.forward` 把所有层的 `head_output` 累加：

```python
head_input = term if head_input is None \
             else head_input[:, :, -L:] + head_term
```

所以：

- 把 α 乘在 `layer1x1` 上 → 只压 **residual 链**，`head_input` 累加完全不受影响
- 最终输出 = `head_scale · head_rechannel(Σ z_i)`，**z_i 一个都没被缩放**

## 四、修正方案：在激活后做逐层增益渐变

作用点改为**每层 `_activation` 输出之后**，一个点同时覆盖两条路径：

```
residual    = x + γ_i · layer1x1(z_i)
head_output = γ_i · z_i            ← 因为 layer1x1 线性，等价于对 res_out 也乘 γ_i
```

`residual_scale` 的旧语义保留为「所有 γ_i 相同」。

### 为什么必须「渐变」而不是固定 α

固定 α 会被训练完全补偿：layer1x1 权重整体放大 1/α 就抵消了。
实测 α=0.5 把残差增长从 480× 只降到 207×（预期 4×，实际 1.8×），
证实了这一点。

渐变 γ_i 是**结构性约束**：后期层要把 γ 补偿回来，需要连续放大 1/γ_i，
15 层累计是天文数字 → 梯度爆炸 → 训练自然不走这条路。

### 配置

```json
"layer_gains": {"mode": "exp", "start": 1.0, "end": 0.3}   // 指数递减
"layer_gains": {"mode": "const", "value": 0.5}              // 常数（对照组）
"layer_gains": [1.0, 1.0, ..., 0.3]                         // 显式列表
```

### 物理意义（这是"模拟电路易实现"的关键）

γ_i = **第 i 层激活输出后的固定电阻分压比**。
模拟电路里就是两个电阻的比值，**零成本、零功耗、零面积增量**，
却能换来动态范围需求的数量级下降。这是纯布线层面的设计自由度。

## 七、诚实的边界

- V_SAT 扫描第一轮数据（V_SAT=4096 时 ESR=44）**已作废**，原因是 bug 1
- α 方案（第六/七批）的结论「α 降低 V_SAT 需求」**已被推翻**，
  `FINAL_A2_ALIGNED.md` 第七节的乐观推断不再成立
- γ 渐变的效果**尚未实测**，本文只记录方案与动机，不给预期数字
- 器件仿真是行为级模型（非 SPICE），绝对值有偏差，相对趋势可信
